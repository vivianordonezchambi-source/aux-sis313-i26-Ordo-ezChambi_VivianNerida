PRÁCTICA N°5 - JavaScript

1. Formas de conectar HTML con JavaScript

Existen dos formas principales de conectar HTML con JavaScript:

a) JavaScript interno

Consiste en escribir el código JavaScript dentro del mismo archivo HTML utilizando la etiqueta script. 

<script>
    console.log("Hola Mundo");
</script>

b) JavaScript externo

Consiste en conectar un archivo .js externo mediante la etiqueta script usando el atributo src. 

<script src="script.js"></script>

2. Cómo visualizar resultados en la consola

Pasos para visualizar resultados de JavaScript en la consola:

  1. Abrir el navegador.
  2. Ingresar a la página HTML.
  3. Presionar F12 o clic derecho → Inspeccionar.
  4. Ir a la pestaña Consola (Console).
  5. Utilizar console.log() en JavaScript para mostrar resultados.
console.log("Hola desde JavaScript");

3. Variables en JavaScript

Las variables son espacios de memoria que permiten almacenar datos.

var

Permite declarar variables, pero actualmente ya no se recomienda porque puede generar errores debido a su alcance. 

var nombre = "vivi";

let

Permite declarar variables que pueden cambiar su valor. 

let edad = 19;
edad = 20;

const

Se utiliza para declarar variables constantes que no cambian. 

const pi = 3.1416;
